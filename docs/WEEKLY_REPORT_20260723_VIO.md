# VIO / ORB-SLAM3 精度优化周报

日期：2026-07-23

## 一、本周工作目标

围绕 RM75 机械臂 TCP 真值评估场景，完善 ORB-SLAM3 纯双目与 Stereo-IMU 的离线评估、配置验证和鲁棒部署链路，提升定位精度、稳定性和结果可追溯性。

## 二、本周主要工作

### 1. 历史评估结果收敛

- 完成历史 RM75 数据的正式结果整理，统一纯双目、Stereo-IMU BA0、Stereo-IMU BA10 与固定权重融合候选的评估口径。
- 对每条轨迹保留独立的 strict-sync 对齐、正式 TCP evaluator 复核、方法选择记录和结果 provenance。
- 明确区分离线 oracle 上限结果与不依赖 GT 的 shadow-gate 可部署结果。

### 2. 新数据集接入与适配

- 接入新增常规 episode 数据和单 MCAP 格式数据。
- 建立从数据导出、ORB-SLAM3 运行、轨迹转换、TCP 评估到结果汇总的自动化链路。
- 为不同数据格式保留独立日志、manifest、逐 episode 目录和后台任务状态，支持失败定位与断点续查。

### 3. Stereo-IMU 配置问题定位

- 对比历史有效 VINS 配置与新数据标定信息，确认问题集中在相机-IMU 外参的坐标变换方向和内部时间偏移解释。
- 明确区分物理标定值与配置文件中的坐标系表达，避免将互逆变换直接混用。
- 验证历史完整配置在新数据上的迁移效果，并保留“仅迁移噪声”和“完整历史标定”两类候选用于对照。

### 4. VIO 鲁棒性策略建设

- 保持纯双目、Stereo-IMU BA0、Stereo-IMU BA10 的独立候选输出，避免假设单一配置对所有轨迹最优。
- 继续采用 shadow-gate 作为部署策略：基于惯性覆盖率、双目/IMU轨迹一致性与极端尺度异常进行 GT-free 决策。
- 明确 fail-closed 原则：IMU 初始化、轨迹生成、诊断或指标异常时，自动回退纯双目。

### 5. 工程化与可复现性改进

- 批量 runner 支持历史 VINS 内部时间偏移的显式透传。
- MCAP 评估路径支持 BA0、BA10、完整历史标定和仅迁移噪声等配置模式。
- 长耗时任务统一采用后台串行执行，避免并发资源冲突和重复运行。
- 保留所有参数、命令、日志、评估产物和配置来源，满足后续复现实验和回归检查需求。

## 三、阶段性结论

- 当前精度退化的主要风险不在于 IMU 数据必然不可用，而在于相机-IMU外参方向、内部时间偏移和初始化策略是否与 ORB-SLAM3 的坐标约定一致。
- 历史有效配置具备迁移价值，但 BA0 与 BA10 的收益具有数据相关性，不能在验证完成前强制指定单一后端策略。
- strict-sync 用于离线轨迹与 GT 的评估对齐，不能替代 VIO 内部相机-IMU时间同步，也不应参与部署时模式选择。

## 四、当前进行中工作

- 继续完成新增 MCAP 数据的完整历史标定 BA0、BA10 评估。
- 汇总新数据上的纯双目、BA0、BA10 和融合候选，生成统一结果表和方法映射。
- 基于完整结果生成新数据的 oracle 结果与 shadow-gate 可部署结果。

## 五、风险与问题

- 单 MCAP 数据的同事版纯双目 shadow 路径仍存在图像目录兼容问题，需要与 VIO 算法表现分开处理。
- 当前配置结论来自已有数据的交叉验证，后续仍需保留独立数据作为冻结配置的泛化验证集。
- 固定权重融合属于轨迹后处理策略，应与 ORB-SLAM3 原生紧耦合 Stereo-IMU 的收益分别报告。

## 六、下周计划

1. 完成剩余后台任务并核验每条结果、日志和 provenance。
2. 输出新数据集的统一结果表、方法映射、时间偏移映射和总结报告。
3. 完成 oracle 与 shadow-gate 的分离汇总，明确离线上限与可部署性能。
4. 根据跨数据集验证结果，固化版本化 VIO profile，包括外参方向、内部时间偏移、噪声模型、初始化和特征参数。
5. 使用未参与配置选择的留出数据进行固定配置回归验证，并记录精度、稳定性和回退行为。
